# Projeto Prático de Python e Shell Script

## Sobre o projeto

Este projeto apresenta uma calculadora simples desenvolvida em Python e em Shell Script (Bash).

O objetivo é praticar conceitos básicos de programação, entrada de dados, estruturas condicionais e operações matemáticas.

## Arquivos do projeto

- `calculadora.py` — código da calculadora desenvolvido em Python.
- `calculadora.sh` — script da calculadora desenvolvido em Shell Script.
- `README.md` — documentação do projeto.

## Como executar o arquivo .sh

Para executar o arquivo `calculadora.sh` em um ambiente Linux, primeiro é necessário dar permissão de execução ao arquivo:

```bash
chmod +x calculadora.sh
